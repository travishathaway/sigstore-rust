# Design: py-sigstore-rust-bindings

## Crate Structure

```
crates/sigstore-python/
├── Cargo.toml
├── pyproject.toml
├── python/
│   └── py_sigstore_rust/
│       ├── __init__.py          # Pythonic re-exports and convenience functions
│       └── _internal.pyi        # Generated by stub_gen (committed to source)
└── src/
    ├── lib.rs                   # #[pymodule] root, registers all classes/functions
    ├── bundle.rs                # PyBundle
    ├── trust_root.rs            # PyTrustedRoot
    ├── verify.rs                # PyVerifier, PyIdentity, PyVerificationResult (internal)
    ├── sign.rs                  # PySigner
    ├── oidc.rs                  # PyIdentityToken
    ├── errors.rs                # Exception hierarchy + Rust→Python error mapping
    ├── runtime.rs               # Embedded tokio Runtime (OnceLock<Runtime>)
    └── bin/
        └── stub_gen.rs          # Runs pyo3-stub-gen to write .pyi files
```

## Cargo.toml Design

```toml
[package]
name = "sigstore-python"
version.workspace = true
edition.workspace = true
rust-version = "1.76"   # per-crate override; pyo3 0.29 requires 1.76+

[lib]
name = "_internal"
crate-type = ["cdylib", "rlib"]
# cdylib = Python extension module
# rlib   = needed so stub_gen binary can link against this crate

[[bin]]
name = "stub_gen"
path = "src/bin/stub_gen.rs"

[dependencies]
pyo3             = { version = "0.29", features = ["abi3-py310"] }
pyo3-stub-gen    = { version = "0.23" }
tokio            = { workspace = true, features = ["rt-multi-thread"] }
sigstore-types   = { workspace = true }
sigstore-bundle  = { workspace = true }
sigstore-verify  = { workspace = true }
sigstore-sign    = { workspace = true }
sigstore-oidc    = { workspace = true }
sigstore-trust-root = { workspace = true, features = ["tuf"] }

[features]
default = []
# pyo3 automatically enables extension-module when building cdylib
```

## Python API

### Bundle

```python
class Bundle:
    @classmethod
    def from_json(cls, data: str | bytes) -> Bundle:
        """Parse a Sigstore bundle from JSON. Raises BundleError if malformed."""

    def to_json(self) -> str:
        """Serialize the bundle to JSON string."""

    @property
    def media_type(self) -> str:
        """The bundle media type string (e.g. 'application/vnd.dev.sigstore.bundle+json;version=0.3')."""
```

### TrustedRoot

```python
class TrustedRoot:
    @classmethod
    def production(cls) -> TrustedRoot:
        """Fetch the Sigstore public-good trusted root via TUF. Raises TrustedRootError."""

    @classmethod
    def staging(cls) -> TrustedRoot:
        """Fetch the Sigstore staging trusted root via TUF."""

    @classmethod
    def github(cls) -> TrustedRoot:
        """Load the GitHub Actions trusted root (embedded, no network)."""

    @classmethod
    def from_json(cls, data: str | bytes) -> TrustedRoot:
        """Parse a trusted root from JSON."""

    @classmethod
    def from_file(cls, path: str) -> TrustedRoot:
        """Load a trusted root from a file path."""
```

### Identity (VerificationPolicy)

```python
class Identity:
    def __init__(self, identity: str, issuer: str | None = None) -> None:
        """
        Specify the expected signer identity.

        Args:
            identity: The signer's identity string (email address or workflow URI).
            issuer:   The OIDC issuer URL. Recommended; if omitted any issuer is accepted.
        """
```

### Verifier

```python
class Verifier:
    @classmethod
    def production(cls) -> Verifier:
        """Create a verifier using the Sigstore public-good trusted root (TUF fetch)."""

    @classmethod
    def staging(cls) -> Verifier:
        """Create a verifier using the Sigstore staging trusted root."""

    @classmethod
    def github(cls) -> Verifier:
        """Create a verifier using the GitHub Actions trusted root (no network)."""

    @classmethod
    def from_root(cls, root: TrustedRoot) -> Verifier:
        """Create a verifier from a pre-loaded TrustedRoot."""

    def verify_artifact(
        self,
        input: bytes,
        bundle: Bundle,
        policy: Identity,
    ) -> None:
        """
        Verify a raw artifact against a Sigstore bundle.

        Raises VerificationError if verification fails.
        """

    def verify_dsse(
        self,
        artifact: bytes,
        bundle: Bundle,
        policy: Identity,
    ) -> tuple[str, bytes]:
        """
        Verify a DSSE envelope bundle.

        Returns (payload_type, payload_bytes) on success.
        Raises VerificationError if verification fails.
        """
```

### IdentityToken

```python
class IdentityToken:
    @classmethod
    def from_jwt(cls, token: str) -> IdentityToken:
        """Parse an OIDC JWT identity token."""

    @classmethod
    def detect_ambient(cls) -> IdentityToken:
        """
        Detect an ambient OIDC credential (e.g. GitHub Actions OIDC token).
        Raises IdentityTokenError if no ambient credential is available.
        """

    @property
    def issuer(self) -> str: ...
    @property
    def subject(self) -> str: ...
    @property
    def identity(self) -> str:
        """Returns 'subject@issuer' formatted string."""
    @property
    def is_expired(self) -> bool: ...
```

### Signer

```python
class Signer:
    @classmethod
    def production(cls, token: IdentityToken) -> Signer:
        """Create a signer using the Sigstore public-good infrastructure."""

    @classmethod
    def staging(cls, token: IdentityToken) -> Signer:
        """Create a signer using the Sigstore staging infrastructure."""

    def sign_artifact(self, input: bytes) -> Bundle:
        """
        Sign artifact bytes and return a Sigstore bundle.
        Records the signature in Rekor and obtains a Fulcio certificate.
        Raises SigningError on failure.
        """

    def sign_dsse(self, payload: bytes, payload_type: str) -> Bundle:
        """
        Sign a DSSE statement and return a Sigstore bundle.
        Raises SigningError on failure.
        """
```

### Module-level convenience

```python
def verify(
    input: bytes,
    bundle: Bundle | str,
    identity: str,
    issuer: str | None = None,
    *,
    trusted_root: TrustedRoot | None = None,
) -> None:
    """
    One-shot verification. Uses production TrustedRoot if not provided.
    bundle may be a Bundle object or a JSON string.
    Raises VerificationError on failure.
    """

def sign(
    input: bytes,
    token: IdentityToken | str | None = None,
    *,
    staging: bool = False,
) -> Bundle:
    """
    One-shot signing. Detects ambient OIDC token if token is None.
    token may be an IdentityToken or a raw JWT string.
    Raises SigningError on failure.
    """
```

## Exception Hierarchy

```python
SigstoreError(Exception)          # base; all errors from this library
├── VerificationError             # raised by verify_artifact / verify_dsse / verify()
├── SigningError                  # raised by sign_artifact / sign_dsse / sign()
├── BundleError                   # raised by Bundle.from_json()
├── TrustedRootError              # raised by TrustedRoot.production() / from_json() / from_file()
└── IdentityTokenError            # raised by IdentityToken.from_jwt() / detect_ambient()
```

All exceptions carry a message string. `VerificationError` and `SigningError` include a `.details` attribute with the underlying Rust error chain.

## Async → Sync Bridging

All async Rust operations are wrapped with a single embedded Tokio runtime:

```rust
// src/runtime.rs
static RUNTIME: OnceLock<tokio::runtime::Runtime> = OnceLock::new();

pub fn get_runtime() -> &'static tokio::runtime::Runtime {
    RUNTIME.get_or_init(|| {
        tokio::runtime::Builder::new_multi_thread()
            .enable_all()
            .build()
            .expect("Failed to build Tokio runtime")
    })
}
```

Async calls release the Python GIL:

```rust
#[pyfunction]
fn detect_ambient(py: Python<'_>) -> PyResult<PyIdentityToken> {
    py.allow_threads(|| {
        get_runtime().block_on(async {
            IdentityToken::detect_ambient().await
        })
    })
    .map(PyIdentityToken::from)
    .map_err(Into::into)
}
```

## Stub Generation

`pyo3-stub-gen` annotations are placed on every `#[pyclass]` and `#[pyfunction]`. The `src/bin/stub_gen.rs` binary is run as part of the dev workflow:

```
cargo run --bin stub_gen
```

This writes `python/py_sigstore_rust/_internal.pyi`. This file is committed to source control and validated in CI with `mypy stubtest`.

## Wheel Distribution

- **abi3 wheels**: `pyo3 = { features = ["abi3-py310"] }` — one wheel per platform, works on Python 3.10+
- **Platforms**: Linux x86_64, Linux aarch64 (manylinux_2_28), macOS x86_64, macOS aarch64, Windows x86_64
- **Windows**: uses `aws-lc-rs` `prebuilt-nasm` feature to avoid NASM install requirement in CI
- **Build backend**: Maturin ≥ 1.0
- **CI**: `PyO3/maturin-action@v1` with `working-directory: crates/sigstore-python`

## Workspace Integration

Add to `Cargo.toml` workspace members:
```toml
"crates/sigstore-python",
```

The `sigstore-python` crate is NOT added to `workspace.dependencies` (same pattern as `sigstore-conformance`) since no other Rust crate depends on it.
